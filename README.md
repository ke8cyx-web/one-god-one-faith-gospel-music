# One God One Faith Gospel Music

A free gospel music community app for mobile phones and computers.

## Features being built
- Member registration and sign-in
- Gospel artist profiles
- Original music uploads with administrator approval
- Music streaming, likes and comments
- Green, gold and white ministry branding

## Deployment
Host the static website with GitHub Pages. Configure Supabase Authentication, database tables, Row Level Security, private audio storage and a secure playback endpoint before enabling live uploads.

## Security
Do not put Supabase service-role keys or other private secrets in browser code. Uploaded songs should remain private until approved.

This is a work-in-progress; do not advertise it as fully operational until the database, playback and moderation workflows have been tested.
